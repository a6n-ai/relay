Email [support@a6n.ai](mailto:support@a6n.ai). Questions about access or limits go to the same address, or to [sales@a6n.ai](mailto:sales@a6n.ai).

Access to Relay is by invite. Ask a workspace owner or admin to invite a new teammate under **Settings**, then **Invites**.

## What to include

- Your workspace and app name.
- The message id, for a sending problem. It is the `messageId` the API returned, and it is in the message's URL in **Messages**.
- The time of the request and the HTTP status you got.
- The request body, with the API key removed.

Never send a full API key or a webhook signing secret. If you shared one by accident, revoke it. Open the app, click the key's menu, and choose **Revoke**. Then create a new key.
